Iterations

選擇 Iteration

點選 Iteration 切換顯示；按 ☆ 固定到左側清單

規劃

勾選此需求需要開發的 repository，並選擇要做在哪個 feature branch。不需修改程式（例如只調整 database 資料）時可以都不勾，Confirm Commit 會自動完成。

Repository 設定

編輯 data/config.json 的 repos。key 是流程紀錄使用的識別名稱，已有紀錄的 repository 請勿改 key。

連線與機密設定

Confirm Commit

填入此需求開發測試通過版的 commit（縮寫即可），並按「檢查」確認 repository 中存在該 commit；也可在「分支圖」中直接點選 commit。

安排預設 Task

將在此 Requirement 底下建立一個同名的 Task（Area / Iteration 沿用 Requirement）。

測試 / 檢核記錄

記下這次的測試場景或驗證方式，之後才能回想起當時的狀況。可以從以下面向記錄：

  • 時間、地點、人員（誰測、誰陪同）
  • 溝通管道：Teams / SharePoint / Email…
  • 裝置、連線（網路、VPN、環境）、使用的資料
  • 不是實際測試而是檢查時：怎麼驗證這件事沒問題（查了哪些資料 / 設定、比對的依據、結果）
圖片 直接按 Ctrl + V 貼上截圖，或拖曳圖片到這裡

設定 UpAgent 連線

切換時會刪除 UpAgent 的設定檔；重新開啟 UpAgent 後會要求輸入 Activation Code，輸入後即自動連線到對應的環境。
