# shell/ — PowerShell scripts run by the app

Run by `app/src/main/powershell.js`: `runPowerShellJson(script, args)` / `runPowerShellLines(script, args, { onLine, onMarker, stderr })` (splits output into lines; `::error::` replaces the error message, other `::<kind>::` markers → `onMarker`) → `child_process.execFile` with `-NoProfile -NonInteractive -ExecutionPolicy Bypass -File`, `cwd=shell/`. Only bare `*.ps1` names inside `shell/` are accepted (so no subfolders). Executable is `powershell.exe` unless the `POWERSHELL` env var overrides it (e.g. `pwsh`).

## Conventions (same as `script/*.py`)
- Named parameters only (the app passes every argument as a string).
- Progress → stdout; result JSON → the file given by `-Out` (UTF-8; a BOM is stripped on read).
- Failure → message to stderr + `exit 1`; the app shows stderr as the error message.
- Save every `.ps1` as **UTF-8 with BOM** (Windows PowerShell 5.1 needs it for Chinese) and set `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`.
- Non-interactive: no `Read-Host` / confirmation prompts.
- Shared helpers live in `Common.ps1` (`Get-DataRoot`, `Write-Result`, `Exit-WithError` (`::error::` + stderr + exit 1), `Invoke-Az` (stderr captured into the exception) / `Invoke-AzCli` (az output shown live), `Read-DotEnv`, `Get-FileHashBase64`, `Format-Size`, `Resolve-ManifestFile`); every script dot-sources it after `param()` with `. (Join-Path $PSScriptRoot 'Common.ps1')` and never redefines those functions. Only same-named helpers that behave differently stay local (`Invoke-Native`, `Get-Setting`).
- Settings: read `data/config.json` with `ConvertFrom-Json` and secrets from `data/.env` (`Read-DotEnv` in `Common.ps1` — same rules as Python: a same-named env var wins). Never add a new config file.
- To wire a new script: a service in `main/services/` calls `runPowerShellJson` → channel in `ipc.js` → method in `preload/index.js`.

## Scripts
- `Restart-AppService.ps1` — test-deploy after-deploy restart (Azure CLI, `az login`; waits until the site answers < 500). Non-interactive copy of `docs/reference/release/Restart-AppService.ps1`.
- `After-ProdDeploy.ps1` — prod after-deploy. Prod is **never restarted immediately**: with `-RestartDate -RestartTime` it calls `Restart-Schedule.ps1 -Action Create` (same session via `&`, failure = `$LASTEXITCODE`); without them it does nothing.
- `Restart-Schedule.ps1` — prod restart scheduling in Azure Automation (`-Action List|Create|Delete`): one-time Schedule + Job Schedule linking the configured Runbook. `az` only for the ARM token; REST via `Invoke-RestMethod` (az.cmd breaks JSON bodies / `&`). Settings in `prodRestart` of `data/config.json`; details in `docs/requirement-flow.md` (§ 正式環境排程重啟).
- `Deploy-Local.ps1` — Local (on-prem Docker) deploy when Local is checked: deploy clone → env branch, optional per-environment `envFile` → `<projectDir>\<envTarget>` (default `.env`), optional pre-build, `docker buildx` → `data/local_deploy/*.tar` (reused on retry) → load + push, `ssh` to replace the container. Non-interactive rewrite of `docs/reference/release/deploy-crmapp*.ps1`; settings in `localDeploy` of `data/config.json`; details in `docs/requirement-flow.md` (§ Deploy stages). `-Environment customer -Customer <key> -CustomerTarget <saas|local>` = 手動佈版's 客戶環境: settings from `customerDeploy`, checks out `-ExpectedCommit` (must be in `-Branch` = prodBranch), copies the customer's `envFile` or (SaaS without one) removes `envTarget`, restores it after the build, writes `data/customer_build/…/*.tar` and stops (no push / ssh).
- `Sync-Repos.ps1` — menu「Git → 同步所有 Repository…」(`main/services/repoSync.js`, renderer `repo-sync-dialog.js`): for every `repos[].path` and `localDeploy.repos.*.projectDir` in `-ConfigPath` (deduped), `git fetch --all` (no `--prune`, case-only branch names break it on Windows) then fast-forward local branches that are only behind their remote upstream (checked-out branch → `merge --ff-only` in its worktree; others → `update-ref` with old-value check). Diverged / `[gone]` branches are left alone; never merges, rebases, pushes or deletes. `-FetchOnly` = report only. Non-interactive rewrite of `feature/Fetch-AllGit.ps1`.
- `Release-UpAgent.ps1` + `1-Get-BlobArtifacts.ps1` / `2-Update-LatestYml.ps1` / `3-Publish-BlobArtifacts.ps1` — UpAgent release; steps, resume logic and stdout markers are in `docs/requirement-flow.md` (§ UpAgent 發佈).
